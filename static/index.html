About CredWise

CredWise (Credit Risk Management) is an automated credit underwriting intelligence platform. It utilizes a gradient boosting model (XGBoost) combined with probability calibration (Platt Scaling) to calculate the statistical likelihood of borrower default.

Algorithm Calibrated XGBoost
Input Features 11 Dimensions
Inference Engine FastAPI (ASGI)
Decision Metric Optimized F1

Disclaimer: Model predictions are statistical risk estimates intended for decision-support and educational assessment. They do not constitute guaranteed outcomes or binding lending determinations.

How the Prediction Pipeline Works

  1. 1. Input Validation: Strict schema validation validates applicant age, earnings, credit tier, debt burden, and bureau history.
  2. 2. Automated Preprocessing: Numerical imputation (median) and categorical encoding (OneHot) prepare feature vectors for the calibrated ensemble.
  3. 3. Calibrated Default Estimation: The model computes a well-calibrated posterior default probability \( P(\text{Default}) \in [0, 1] \).
  4. 4. Optimal Threshold Decision: The output is compared against the optimized F1/Recall decision cutoff to assign Low Risk or High Risk.
